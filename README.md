# dotfiles

個人用のdotfiles管理リポジトリです。zsh、tmux、zellij、starship、miseなどの設定ファイルを一元管理します。

## 要件

- POSIX互換のシェル（sh, bash, zsh等）
- 対応OS: macOS, Linux
- Git

## インストール

```sh
# リポジトリをクローン
git clone <your-repo-url> ~/dotfiles
cd ~/dotfiles

# セットアップを実行
sh init.sh
```

初回実行時にGit設定（名前とメールアドレス）の入力を求められます。

## 管理している設定ファイル

- **zsh** (`.zshrc`) - シェル設定
- **tmux** - ターミナルマルチプレクサ設定
- **zellij** - モダンなターミナルワークスペース
- **starship** - クロスシェルプロンプト
- **mise** - ランタイムバージョンマネージャー
- **SSH** - SSH設定
- **Homebrew** (`.Brewfile`) - パッケージ管理
- **gitmoji** - Gitコミット絵文字設定

## 使い方

### 通常セットアップ
```sh
sh init.sh
```

### Dry-Run（実行内容の確認）
実際の変更を行わず、実行内容のみを確認できます：
```sh
sh init.sh --dry-run
```

### アンインストール
作成したシンボリックリンクと空のディレクトリを削除します：
```sh
sh init.sh --uninstall
```

dry-runと組み合わせて、削除内容を事前に確認することもできます：
```sh
sh init.sh --uninstall --dry-run
```

**注意事項:**
- シンボリックリンクのみを削除します（通常のファイルは削除しません）
- `~/.gitconfig` は削除されません（テンプレートからコピーしたファイルのため）
- init.shで作成した空のディレクトリのみを削除します
- ディレクトリ内に他のファイルがある場合、そのディレクトリは削除されません

## 既存ファイルがある場合

既存のシンボリックリンクは自動的に上書きされますが、通常のファイルやディレクトリが存在する場合はエラーになります：

**通常ファイルの場合:**
```
エラー: SSH設定のリンクに失敗しました
  リンク元: /path/to/dotfiles/src/.ssh/config
  リンク先: ~/.ssh/config
  原因: リンク先に既存のファイル（通常ファイル）が存在します
  解決策: 既存ファイルを削除またはバックアップしてから再実行してください
```

**ディレクトリの場合:**
```
エラー: mise設定のリンクに失敗しました
  リンク元: /path/to/dotfiles/src/.config/mise
  リンク先: ~/.config/mise
  原因: リンク先に既存のディレクトリが存在します
  解決策: 既存ファイルを削除またはバックアップしてから再実行してください
```

エラー発生時は自動的にロールバックされ、作成したシンボリックリンクやディレクトリは削除されます。
